ARS

Advance Rendering System

ARS is a lightweight front-end framework for rapid development. Pages live in /page, the Engine handles rendering, mouse-hover analysis, preloading and cache management — so you focus only on building pages.

Hash Router Rendering Engine Hover Analysis Preloader Cache Management Liquid Glass UI 
ADVANCE-RENDARING-SYSTEM/
├── index.html          ← root page
├── .env                ← blank (use for API keys later)
├── page/               ← your pages live here
│   ├── info.html
│   ├── status.html
│   └── start.html
├── JS/                 ← app scripts (router, boot)
├── CSS/                ← liquid glass stylesheet
├── Engine/             ← rendering · hover · preloader · cache
└── Media/              ← images, icons, media assets
