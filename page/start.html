Quick Start — Add Your Own Page

  1. Create page/myPage.html with your content.
  2. Register it in JS/app.js: ARS.Router.register("myPage", "page/myPage.html");
  3. Add a nav link in index.html: <a href="#myPage" data-route="myPage" class="nav-link">My Page</a>
  4. (Optional) For file:// support, add the HTML string to the embedded map in JS/router.js.

The Engine auto-preloads and caches every route, and tracks FPS, hover analytics and cache size in real time.

Engine API

  1. ARS.Renderer.stats() — fps, frameTime, renders, uptime
  2. ARS.Cache.set / get / stats / clear() — LRU cache with byte tracking
  3. ARS.Hover.stats() — hover target, times, heat-map top element
  4. ARS.Preloader.show / hide / preload() — glass loading overlay
  5. ARS.Router.register / load / current / pageCount() — hash routing + page cache

Folder Roles

  • index.html — shell: nav, preloader, #app container, script order
  • page/ — one HTML file per route (content only, no full document)
  • JS/ — router + boot; register every new page here
  • CSS/ — Liquid Glass design system
  • Engine/ — renderer, hover, preloader, cache (do not remove)
  • Media/ — logos, images, icons
  • .env — optional API keys for later integrations
